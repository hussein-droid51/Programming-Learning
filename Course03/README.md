03 - Programming Using C++ – Level 1
This course is an introduction to programming fundamentals using C++.
It focuses on learning core programming concepts, understanding C++ syntax, and applying these concepts through practical tasks and exercises.

This course represents the first hands-on experience with writing code and implementing programming logic.

During this course, I learned the following concepts and fundamentals in C++:

Introduction to programming using C++
Variables
Data types, sizes, and ranges
Operators:
Increment / Decrement (++ / --)
Arithmetic operators
Assignment operators
Relational operators
Logical operators
Some mathematical functions in C++
Structures
Enums
Data type conversion
Strings
Functions
Variable scope (local vs global variables)
Arrays
Conditional statements:
if
if..else
else..if
switch..case
Loops:
for loop
while loop
do...while loop
